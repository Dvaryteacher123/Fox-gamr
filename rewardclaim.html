Pata Tuzo Yako

Ingiza namba ya claim uliyopewa na Admin ili kupakua mchezo wako wa VIP.

Jinsi ya kupata Claim Code yako:

1

Wasiliana na Admin — Mwambie admin akupatie claim code (kwa mfano: DVARY-ABCDEF).

2

Nakili Code — Ukishaipata, weka code kwenye sanduku hapo chini au bonyeza "Nakili Code" ikiwa tayari ipo.

3

Thibitisha Claim — Bonyeza "Thibitisha Claim & Download" ili kufungua mchezo wako.

4

Pakua Mchezo — Baada ya kuthibitishwa, utaelekezwa kwenye ukurasa wa kupakua mchezo wako wa VIP.

Kumbuka: Claim code inatumika mara moja tu. Hakikisha unaitumia kabla ya kuisha muda.
